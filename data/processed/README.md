## ★ The three evaluation sets — what makes each one different

The most important distinction in this folder:

| File | Pairs | Negative type | What it tests |
|---|---|---|---|
| `consistency_eval.jsonl` | 600 | **Cross-video** — thumb from vid A, query for A, video B (different video) | Pipeline can tell when query/video are about different topics |
| `consistency_eval_hard.jsonl` | 584 | **Within-video** — thumb from vid A but a frame OUTSIDE its `relevant_window`, same video A, same query | ★ **Temporal grounding** — can pipeline localize the correct moment IN a video? |
| `consistency_eval_query_mismatch.jsonl` | 600 | **Query-mismatch** — same thumb, same video, but a query about a DIFFERENT topic | ★ **Query path** — does the pipeline actually use the query, or just thumb-video visual similarity? |

### How to tell which is which (programmatic check)

```python
import json

def classify_negative(record):
    if record['label'] != 0:
        return 'positive'
    same_vid = record['thumb_vid'] == record['video_vid']
    if 'out_of_window_clip_id' in record:
        return 'within-video'
    if 'correct_query_was' in record or 'wrong_query_from' in record:
        return 'query-mismatch'
    if not same_vid:
        return 'cross-video'
    return 'unknown'

for fname in ['consistency_eval.jsonl',
              'consistency_eval_hard.jsonl',
              'consistency_eval_query_mismatch.jsonl']:
    with open(fname) as f:
        rs = [json.loads(l) for l in f if l.strip()]
    from collections import Counter
    print(f'{fname}: {Counter(classify_negative(r) for r in rs)}')
```

Expected output:
```
consistency_eval.jsonl:                Counter({'positive': 300, 'cross-video': 300})
consistency_eval_hard.jsonl:           Counter({'positive': 300, 'within-video': 284})
consistency_eval_query_mismatch.jsonl: Counter({'positive': 300, 'query-mismatch': 300})
```
